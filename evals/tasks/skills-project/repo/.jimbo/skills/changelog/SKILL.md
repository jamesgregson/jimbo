---
name: changelog
description: Record a change in CHANGELOG.md. Use after any change to the code's behaviour or its public functions.
---
Add one line under `## Unreleased` in CHANGELOG.md for each change, newest first:

- `- Added: <function name>.` for a new public function
- `- Changed: <what changed>.` for a change in behaviour
- `- Fixed: <what was wrong>.` for a bug fix

Don't edit the sections of released versions.
